# Memory Bank - Docidv iframe Test Project

## Project Overview

An iframe testing application for the Docidv service. Allows users to dynamically configure the iframe URL, dimensions, sandbox permissions, and allow-attribute permissions via a left sidebar.

## Sidebar Sections (left panel)

1. **URL Settings**
   - Text input pre-filled with default URL
   - Apply URL button + Enter key support

2. **Dimensions**
   - Height (px) and Width (px) number inputs (empty = auto/fill)
   - Apply button sets `iframeInner` to exact pixel size; wrapper scrolls if oversized

3. **Sandbox controls**
   - "Enable sandbox attribute" toggle (removes the attribute entirely when unchecked)
   - 12 individual sandbox checkboxes (allow-downloads, allow-forms, allow-modals, allow-orientation-lock, allow-pointer-lock, allow-popups, allow-popups-to-escape-sandbox, allow-presentation, allow-same-origin ✓, allow-scripts ✓, allow-top-navigation, allow-top-navigation-by-user-activation)
   - Pre-checked: allow-same-origin, allow-scripts, allow-forms, allow-popups, allow-modals
   - "Sandbox documentation" MDN link
   - Apply button

4. **Allow attributes**
   - 7 feature-permission checkboxes, all pre-checked: camera, microphone, geolocation, fullscreen, clipboard-read, clipboard-write, web-share
   - Apply button rebuilds `allow="…"` from checked values (semicolon-separated)

## Layout & Design

- **Fullscreen**: `html, body` height 100vh, no body padding, no max-width container
- **Dark theme**: sidebar `#18242e`, iframe area `#1c2830`
- **Responsive**: stacks vertically (sidebar on top, max-height 45vh) below 768px
- **Collapsible sections**: chevron rotates on collapse; toggle `.hidden` on body

## iframe Defaults

```
src:     https://go.dev8.idnow.de/docidv/channel-chooser/web?identToken=DV8-CQGVP
allow:   camera; microphone; geolocation; fullscreen; clipboard-read; clipboard-write; web-share
sandbox: allow-same-origin allow-scripts allow-forms allow-popups allow-modals
```
